# إعداد BotFather

1. `/newbot` ← الاسم: **CivilBot | المهندس المدني** ← المعرف: CivilBot (أو المتاح)
2. `/setuserpic` صورة مربعة 640×640 (شعار خوذة + كمرة)
3. `/setcommands` ← الصق محتوى `botfather_commands.txt` (البوت يضبطها تلقائياً أيضاً عند التشغيل)
4. `/setinline` اختياري، `/setjoingroups` ← Disable (البوت للاستخدام الفردي)
5. الإصدار مجاني (FREE_MODE=1)، فلا تحتاج تفعيل المدفوعات. كود Stars باقٍ إذا احتجته لاحقاً مع FREE_MODE=0
6. `/terms` و `/privacy` موجودة
7. `/setmenubutton` ← رابط WEBAPP_URL (محرر الكمرات Mini App)

## أوامر الأدمن
- `/stats` المؤشرات · `/grant <id> pro 30` · `/revoke <id>`
- `/broadcast نص` · `/backup`
